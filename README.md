# ระบบประเมินพนักงาน — หน้าบ้าน (git.v2)

ไฟล์ชุดนี้คือหน้าบ้านทั้งหมดสำหรับ GitHub Pages (วางทับของเดิมได้เลย)

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | แอปทั้งหมดในไฟล์เดียว (build จาก `src/` ด้วย `node build-prod.js`) |
| `config.js` | URL ของ Google Apps Script Web App (`window.__GSHEET_API__`) |
| `.nojekyll` | บอก GitHub Pages ไม่ต้องประมวลผล Jekyll |

## สิ่งที่เปลี่ยนใน v2 (13 ต.ค. 2569)
- เร็วขึ้น: เข้าระบบ 1 คำขอ (login + ข้อมูลตั้งต้นมาพร้อมกัน), รีเฟรชหน้าเปิดได้ทันทีจากข้อมูลที่จำไว้,
  คำขอนับ/ค้นหาที่ยิงพร้อมกันถูกรวมเป็นคำขอเดียว (batch), ผลลัพธ์ที่ไม่เปลี่ยนไม่ถูกส่งซ้ำ (notModified ตามเวอร์ชันตาราง)
- ไฟล์แนบ (รูป/เอกสาร/ใบเซ็น) อัปโหลดขึ้น Google Drive โฟลเดอร์ "งาน HR KPI/ไฟล์แนบ/<รอบ>/<รหัสพนักงาน>/"
  ในชีตเก็บเฉพาะ driveId — เปิดดู/ดาวน์โหลดผ่านระบบ (ต้องเข้าระบบ) ขนาดสูงสุด 8MB/ไฟล์
- ต้องใช้คู่กับ Code.gs เวอร์ชัน API v4 (gas/Code.gs) — ติดตั้งแล้วใน Apps Script "Script HR-KPI"
